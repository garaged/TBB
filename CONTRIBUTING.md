# Contributing to TBB

TBB welcomes contributions that protect its privacy-first, local-first mission.

## Before coding

Read [AGENTS.md](AGENTS.md), the relevant specification, architecture, and ADRs. Propose or update a specification/ADR before altering product behavior, persistence, sharing, security, or dependencies.

## Pull requests

- Keep one focused outcome per PR.
- Add or update tests and traceability.
- Do not add telemetry, ads, trackers, paywalls, remote account systems, or a TBB-operated data backend.
- Preserve deterministic accounting and private/shared boundaries.
- Explain test evidence and residual risk.

## Support links
