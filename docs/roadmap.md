# Roadmap

## M0 — Foundation

Intent, architecture, sharing decision, threat model, specs, traceability, repository policy, contribution/license/support policy, and baseline CI.

## M1 — Secure application foundation

Swift project, modular boundaries, design system, accessible app shell, local lock, Face ID/Touch ID, Privacy Mode, local data bootstrap.

## M2 — Ledger

Accounts, categories, transactions, transfers, deterministic balances, fast capture, history/search.

## M3 — Dashboards

Reusable time-range navigator, insights projections, configurable cards, responsive iPhone/iPad layouts.

## M4 — Budgets

Budget planning, period rules, rollover policy, progress, alerts, recurring items.

## M5 — iCloud and household sharing

Private/shared persistent stores, invite/accept/manage/revoke flows, offline recovery, audit projection.

## M6 — Backup and restore

Portable versioned archive, optional password encryption, restore preflight, migration/recovery evidence.

## M7 — Watch

Focused transaction capture, today’s budget status, privacy-first glance behavior.

## M8 — Release hardening

Performance, accessibility, localization, migrations/rollback, SBOM/provenance, clean-device acceptance.
